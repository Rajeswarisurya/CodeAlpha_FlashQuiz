# Study Flashcards App

A clean, lightweight flashcard quiz web application built with vanilla HTML, CSS, and JavaScript.

## Features
- **Interactive Flashcards:** View questions on the front and toggle answers with the **Show Answer** button.
- **Deck Navigation:** Move seamlessly through cards using **Previous** and **Next** controls.
- **Custom Card Management:** Add new flashcards, edit existing cards, or delete cards anytime.
- **Persistent Storage:** Automatically saves your study deck in the browser via `localStorage`.

## How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Open `index.html` in any web browser.

## Deploy on GitHub Pages
1. Push all files to a GitHub repository.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main` (or `master`) and `/ (root)`, then click **Save**.
